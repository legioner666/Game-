# Parasite Evolution — Unity prototype source

Статус: перша реалізація ігрового циклу, 15.11.2026. Код ще не імпортовано й не запущено в Unity; APK не зібрано. Статичний розбір C# не є компіляцією або тестом на телефоні.

## Що написано

- Зв'язна лабораторна карта з трьома зонами, двома проходами між сусідніми зонами й базою. Основні проходи доступні від початку.
- Процедурний згусток слизу та щупальця з висуванням, слабким згином, закріпленими контактами й скороченням. Модель створюється кодом; фінального скульпта/FBX немає.
- Лівий сенсорний джойстик, три праві здібності, адаптація до safe area, обидві альбомні орієнтації та пауза при переході у фон.
- Автоматичне захоплення доступних цілей; обмеження місткості, вантаж і його переробка на базі. Біомаса дає рівні, геном витрачається на розвиток.
- Покращення швидкості захоплення, місткості, швидкості руху, радіуса, каналів і здоров'я. Радіус та додаткові канали у цій версії потребують рівня 2.
- AB-PULL, AB-MOVE та AB-DAMAGE з окремими КД; відкриття двох додаткових здібностей за геном.
- П'ять власних завдань: зразки, повернення на базу, покращення, дослідження й Наглядач.
- Два прості режими звичайних противників і механізований Наглядач із попередженням атаки.
- Збереження вантажу, коштів, біомаси, покращень, завдань, позиції й залишків КД. Запис через тимчасовий файл, резервну копію та перевірку revision. Невідома новіша схема не перезаписується.
- Повернення після смерті на базу з частковим штрафом; однаковий serial не списується двічі.

## Числа, які ще не погоджені

Усі числові параметри зосереджені в `Balance` у [ProfileData.cs](Assets/_Game/Scripts/ProfileData.cs) або позначені тут як прототипні. Це не затверджений баланс повної гри.

| Параметр прототипу | Значення / обмеження |
| --- | --- |
| Початкова місткість | 6 одиниць |
| Початкова здібність | AB-PULL безкоштовно; це попередня пропозиція D-11 |
| Ціна AB-MOVE / AB-DAMAGE | 35 / 80 геному |
| КД AB-PULL / AB-MOVE / AB-DAMAGE | 4 / 7 / 13 с |
| Штраф смерті | **Тестові 10% коштів**, округлення вниз; власник погодив лише часткову втрату, відсоток відкритий |
| Вантаж, біомаса й покращення після смерті | Зберігаються в цій реалізації; деталі B-01 ще відкриті |
| Сейв після смерті | Одна стартова база; кілька сейв-зон і вибір останньої ще не реалізовані |
| Повторна поява ворогів | Звичайні 25 с, Наглядач 90 с та віддалення героя; тимчасові параметри |
| Щупальця | 6 опорних каналів анімації, 3 робочі канали; не всі видимі одночасно. Остаточну анатомічну кількість не затверджено |
| Мутації | Поки статистичні покращення; каталог 12 карток і три повні художні форми ще не реалізовані |

## Середовище

Зафіксовано Editor **6000.3.11f1**, URP **17.3.0**, Input System **1.16.0**, uGUI **2.0.0**, Test Framework **1.6.0**. Редактор і Android Build Support повинні працювати на зовнішній підтримуваній машині. Це не інструкція запуску Unity Editor у Termux.

Вибір версій спирається на [реліз Editor](https://unity.com/releases/editor/whats-new/6000.3.11f1) та [офіційний приклад Unity з набором пакетів 6.3](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples/blob/main/CHANGELOG.md). Сумісність саме цього проєкту ще треба перевірити імпортом. `packages-lock.json` створюється реальним Package Manager; вигаданий lock-файл не додавався.

## Відкриття та запуск у редакторі

1. Відкрити каталог `parasite-evolution/` через Unity Hub у версії 6000.3.11f1 й дочекатися імпорту пакетів.
2. Переконатися, що не виникло compile errors. Editor-метод `Prepare` створює URP-налаштування та матеріал у `Assets/_Game/Generated` і `Resources`.
3. Виконати **Parasite → Create and open bootstrap**, потім **Play**. Runtime-код створює сцену, героя та UI.
4. У редакторі доступні WASD, 1/2/3 для здібностей, Escape для паузи; джойстик і кнопки також працюють через UI.
5. Запустити **Window → General → Test Runner → EditMode**. Тести економіки та відновлення запису підготовлені; у поточному середовищі їх не виконано.

Після першого імпорту потрібно переглянути й зафіксувати справжні згенеровані URP-асети, `.meta`, lock-файл і змінені налаштування. Поточний матеріал і рендерер створює наш Editor-код, а не сторонній асет-пак.

## Android debug APK

Потрібні активований Unity, Android Build Support, SDK/NDK/JDK та підтримка IL2CPP. У Build Profiles вибрати Android, переключити платформу й виконати **Parasite → Build Android debug APK**. Ціль — ARM64, мінімальний API 26, обидва альбомні боки.

Для вже підготовленого зовнішнього Editor можна викликати:

```bash
"$UNITY_EDITOR" -batchmode -nographics -quit \
  -projectPath "$PARASITE_PROJECT_PATH" -buildTarget Android \
  -executeMethod ParasiteEvolution.Editor.PrototypeBuild.BuildAndroid \
  -logFile "$PARASITE_PROJECT_PATH/Builds/build.log"
```

Перед командою створити каталог `Builds`. `UNITY_EDITOR` і `PARASITE_PROJECT_PATH` — шляхи на зовнішній машині, не вже наявні значення на телефоні. Очікуваний результат успішної збірки: `Builds/ParasiteEvolution-debug.apk`; такого файла в цій редакції ще немає. Використовується debug-підпис Unity; ключ старої Crown Rush не підключається.

GitHub Actions / Unity Build Automation ще не підключені та ліцензія не перевірена. Наявний workflow `godot/` збирає іншу гру.

## Межі цієї реалізації

Це власний початковий прототип видимого циклу з ролика `5139.mp4`, не повна реалізація всього контенту вихідної гри. Немає реклами, платежів, VIP, серверів, аналітики, звуку, фінальної графіки, повної карти, 12 карток мутацій або потокового завантаження світу. Навігація противників спрощена; складні обходи перешкод ще потрібні.

Положення героя авторитетно змінює `CharacterController`, опорні контакти й зміни довжини створюють процедурну презентацію. Відчуття підтягування маси, точність контакту й збіг фаз необхідно оцінити в реальній сцені; фізична симуляція сили щупалець не заявляється.

Статичні перевірки відокремлені від Unity-імпорту, EditMode-тестів, збірки, встановлення й реального ігрового тесту. Продуктивність на Android не виміряна.

[Фактичні результати перевірки](VALIDATION.md) містять виконані й невиконані кроки окремо.
